잔월 호텔 · 클래식 일러스트 MOD 1.1.0

1. 게임을 실행하고 타이틀 > MOD 관리 > MOD 폴더 열기를 누릅니다.
2. 이 ZIP을 풀어 나온 ClassicIllustrated 폴더를 열린 Mods 폴더 안에 넣습니다.
   올바른 구조: Mods/ClassicIllustrated/manifest.json
3. 게임에서 목록 새로고침을 누르고 클래식 일러스트를 선택합니다.
4. 타이틀로 돌아가 이어하기를 누릅니다. 기본 게임의 진행을 공유합니다.

게임 ZIP에는 이 MOD가 들어 있지 않습니다. 별도로 설치해야 합니다.
기존 동일 MOD가 있다면 사용자 수정본을 백업한 뒤 새 폴더로 교체하세요.

인물별 기본 그림 + 대화 자세 2종, 배경, 블록, 장애물, 수집품을 교체합니다.
새 도식: 턱 짚고 생각하기 / 손가락 들어 설명하기.
새 문 선생: 책 펼쳐 회상하기 / 가슴에 손을 얹고 웃기.
이미지는 AI 생성 그림입니다. manifest 좌표는 원본 PNG의 왼쪽 아래 기준입니다.
flipInDialogue는 대화 화면에서 해당 캐릭터 그림만 좌우 반전하는 선택 항목입니다.
